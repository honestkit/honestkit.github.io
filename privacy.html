Privacy

We collect nothing.

This website

No analytics, no cookies, no third-party scripts, fonts or CDNs. The free tools run entirely in your browser; what you paste is never sent anywhere. The one exception is the DNS lookup tool: when you press Look up, your browser sends the domain name (only that) to Cloudflare's public DNS-over-HTTPS resolver, cloudflare-dns.com. The site is static and hosted on GitHub Pages, which (like any web host) may keep standard server logs such as IP addresses; see GitHub's privacy statement.

The browser extensions

PlainHeaders, PlainTables, MDGrab, PlainLinks and PlainInspect collect no user data, contain no analytics and load no remote code. Each extension's store listing links its own privacy policy with the exact permissions it uses. If you buy an optional Pro upgrade, the payment and your email address are handled by ExtensionPay / Stripe, not by us.

Apify data tools

These run on Apify under your Apify account and are governed by Apify's terms and privacy policy. The company enrichment tool returns company data only — no personal emails.
