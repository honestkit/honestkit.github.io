Honestkit — small, honest tools.

No tracking, no signup. Browser extensions that ask for as little access as possible, free converters that run entirely in your browser, and pay-per-result data tools.

Chrome extensions

  • PlainHeaders — Add, change or remove HTTP request & response headers. Open source, no tracking, access only to sites you choose.
  • PlainTables — Copy any web table to Excel, Google Sheets, CSV or Markdown in one click. No row limits, no account, no tracking.
  • MDGrab — Turn any article or selection into clean Markdown for Obsidian, notes or LLM prompts. No signup, no limits, no tracking.
  • PlainLinks — Extract every link on a page or selection: dedupe, filter by text or regex, copy or export to CSV/XLSX. No tracking.
  • PlainInspect — Hover any text to see its font, size, weight and colors. See every font and color a page uses. No tracking.
