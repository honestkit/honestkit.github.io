ComfyUI --directml: No module named 'torch_directml' (fix)

ModuleNotFoundError: No module named 'torch_directml' appears when ComfyUI is started with --directml and the torch-directml package is missing. We reproduced it on ComfyUI v0.37.0 and checked what installing the package would do first.

1. The error

ComfyUI v0.37.0 started with the DirectML flag in a venv without the torch-directml package:

python main.py --directml
[INFO] Checkpoint files will always be loaded safely.
[WARNING] WARNING: torch-directml barely works, is very slow, has not been updated in over 1 year and might be removed soon, please don't use it, there are better options.
Traceback (most recent call last):
  File "/path/to/ComfyUI/main.py", line 251, in <module>
    import execution
  File "/path/to/ComfyUI/execution.py", line 17, in <module>
    import comfy.model_management
  File "/path/to/ComfyUI/comfy/model_management.py", line 114, in <module>
    import torch_directml
ModuleNotFoundError: No module named 'torch_directml'

ComfyUI exited with code 1. --directml makes comfy/model_management.py run import torch_directml (line 114) at startup, and that package is not in ComfyUI's requirements.txt, so a normal install never has it. Note the warning ComfyUI itself prints just before the traceback: it says torch-directml barely works, is very slow and might be removed.

2. Before you pip install it: it downgrades torch

The newest torch-directml on PyPI is 0.2.5.dev240914 (uploaded 2024-09-15). It pins torch==2.4.1 and torchvision==0.19.1. A dry run in our venv with torch 2.9.0:

(Output from uv pip install --dry-run.) Installing it would replace your torch with 2.4.1, which can break custom nodes that need a newer torch. It also only has wheels for CPython 3.8 to 3.12 (Windows and manylinux x86_64). On Python 3.13, as used by recent portable builds:

3. Fix

  • Simplest: drop --directml. Started without it (here with --cpu), the same ComfyUI got through startup and exited 0. If you have an NVIDIA card, install the CUDA build of torch and run with no flag; for AMD, look at ComfyUI's README for the current ROCm instructions for your OS.
  • If you really need DirectML: use a separate venv on Python 3.12 or older and run python -m pip install torch-directml there, accepting torch 2.4.1. Run ComfyUI with that venv's Python. We could not test DirectML itself (it needs Windows or WSL with a DirectX 12 GPU).

Frequently asked questions

Does torch-directml work with Python 3.13?

No. Its latest release (0.2.5.dev240914) only has wheels for CPython 3.8 to 3.12, so pip finds no matching distribution on 3.13.

Will installing torch-directml change my torch version?

Yes. It pins torch==2.4.1 and torchvision==0.19.1; our dry run would have replaced torch 2.9.0.
