Keras 3: AttributeError module 'keras' has no attribute (tested)

After upgrading to Keras 3, AttributeError: module 'keras.utils' has no attribute 'np_utils', 'keras.layers' has no attribute 'experimental', 'keras.backend' has no attribute 'get_session' and the keras.optimizers.legacy ImportError all come from removed Keras 2 paths. Each was checked on Keras 3.15 below, with its replacement.

keras.optimizers.legacy is a trap: the attribute exists, but using it fails:

import keras

try:
    keras.optimizers.legacy.Adam(learning_rate=1e-3)
except ImportError as e:
    print("ImportError:", e)

If you cannot change old code yet, the error message itself gives the escape hatch: pip install tf_keras and set TF_USE_LEGACY_KERAS=True before importing TensorFlow, so tf.keras is Keras 2 again (we did not run that path).

Frequently asked questions

What replaces keras.utils.np_utils.to_categorical?

keras.utils.to_categorical; the np_utils submodule no longer exists.

What replaces keras.layers.experimental.preprocessing?

The same layers directly under keras.layers, e.g. keras.layers.Rescaling and keras.layers.RandomFlip.

Can I still use keras.optimizers.legacy?

Not in Keras 3. Use keras.optimizers.Adam etc., or install tf_keras and set TF_USE_LEGACY_KERAS=True to keep Keras 2.
