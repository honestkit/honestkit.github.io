ComfyUI: ModuleNotFoundError: No module named 'aiohttp' (fix)

ModuleNotFoundError: No module named 'aiohttp' stops ComfyUI at startup, before any model or custom node loads. We reproduced it on ComfyUI v0.37.0 and fixed it.

1. The error

ComfyUI v0.37.0 started in a venv where everything from requirements.txt is installed except aiohttp:

python main.py
Traceback (most recent call last):
  File "/path/to/ComfyUI/main.py", line 27, in <module>
    from app.assets.manager import AssetManager, default_asset_manager
  File "/path/to/ComfyUI/app/assets/manager.py", line 4, in <module>
    from aiohttp import web
ModuleNotFoundError: No module named 'aiohttp'

ComfyUI exited with code 1 before loading any nodes: main.py line 27 imports app/assets/manager.py, which does from aiohttp import web at line 4. aiohttp is the web framework ComfyUI's server and UI run on, and it is listed in requirements.txt (aiohttp>=3.11.8), so seeing it missing usually means the requirements were never installed into the Python that runs ComfyUI, or something uninstalled it.

2. Fix: install requirements.txt with the same Python

From the ComfyUI folder, using the Python that starts ComfyUI (your venv's python; in the Windows portable build, ..\python_embeded\python.exe run from inside the ComfyUI folder):

python -m pip install -r requirements.txt
Collecting aiohttp>=3.11.8 (from -r requirements.txt (line 14))

If pip says aiohttp is already installed and the error stays, you are installing into a different Python than the one running ComfyUI. See ComfyUI: No module named 'yaml' for how to find the right one.

Frequently asked questions

Is aiohttp required by ComfyUI?

Yes. It is in requirements.txt (aiohttp>=3.11.8), ComfyUI's web server runs on it, and main.py imports it during startup, so ComfyUI exits with code 1 without it.

I installed aiohttp but still get the error. Why?

It went into a different Python. Run python -m pip with the same python (or python_embeded\python.exe) that starts ComfyUI.
