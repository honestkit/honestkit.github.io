Matplotlib and NumPy 2 compatibility (tested)

Matplotlib 3.8.3 and older fail at import matplotlib under NumPy 2 with ImportError: numpy.core.multiarray failed to import. Matplotlib 3.8.4 is the first release that supports NumPy 2. Pin numpy<2 or upgrade; tested below.

1. Reproduce: Matplotlib 3.8.3 with NumPy 2

A Python 3.11 venv with matplotlib==3.8.3, then numpy==2.2.6 installed in a second command (a single command that asks for both is refused, because 3.8.3 requires numpy<2). b1.py:

import numpy
print("numpy", numpy.__version__)
import matplotlib
print("matplotlib", matplotlib.__version__)
matplotlib.use("Agg")
import matplotlib.pyplot as plt
plt.plot([1, 2, 3], [1, 4, 9])
plt.savefig("out.png")
print("saved out.png")

Output, exit code 1 (paths shortened to /venv):

ImportError: numpy.core.multiarray failed to import

Unlike SciPy or OpenCV there is no _ARRAY_API not found line here: the inner error is an ImportError raised from numpy/core/_multiarray_umath.py whose message is the NumPy 1.x banner itself, and the outer one is ImportError: numpy.core.multiarray failed to import from matplotlib._path. It fails at import matplotlib, before any plotting. The resolver states the conflict:

$ uv pip check
Found 1 incompatibility
The package `matplotlib` requires `numpy>=1.21,<2`, but `2.2.6` is installed

2. Which Matplotlib versions support NumPy 2

From the PyPI Requires-Dist metadata, confirmed by running b1.py on 3.7.5, 3.8.3 (both fail as above) and 3.8.4 (works). Matplotlib 3.8.4 is the first release that supports NumPy 2.

MatplotlibNumPy requirementNumPy 2 OK?
3.7.5numpy>=1.20, <2No
3.8.3numpy>=1.21, <2No
3.8.4numpy>=1.21Yes (first)
3.9.0numpy>=1.23Yes

3. Fix: pin numpy<2, or upgrade Matplotlib to 3.8.4+

$ pip install "numpy<2"
$ python b1.py
numpy 1.26.4
matplotlib 3.8.3
saved out.png

Smallest upgrade that keeps NumPy 2:

$ pip install "matplotlib==3.8.4"
$ python b1.py
numpy 2.2.6
matplotlib 3.8.4
saved out.png

Or the latest (on Python 3.11 this resolved to Matplotlib 3.11.2 with NumPy 2.4.6):

$ pip install -U matplotlib numpy
$ python b1.py
numpy 2.4.6
matplotlib 3.11.2
saved out.png

4. The opposite error: Matplotlib requires numpy>=1.25

Fix with pip install -U numpy, or pin an older Matplotlib if something else holds NumPy back.

In a notebook, restart the kernel after changing versions: a running process keeps the NumPy it already imported. New deprecations after upgrading: Matplotlib deprecation warnings. Same NumPy 2 problem in other libraries: SciPy, scikit-learn, OpenCV, pandas, the general banner. All changes: NumPy 2 breaking changes.

Frequently asked questions

Which Matplotlib version supports NumPy 2?

Matplotlib 3.8.4: its metadata drops the numpy<2 cap, and it imported and saved a plot with numpy 2.2.6 in this test. 3.8.3 and 3.7.5 failed.

How do I fix import matplotlib failing after upgrading NumPy?

pip install "numpy<2", or pip install -U matplotlib (3.8.4 or newer).
