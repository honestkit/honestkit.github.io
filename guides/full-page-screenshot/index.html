How to take a full-page screenshot of a website

Every major desktop browser can capture a whole scrolling page without an extension. Here is how, plus the command line for many pages.

1. Chrome and Edge: DevTools command

  1. Open DevTools: F12 or Ctrl+Shift+I (⌘+⌥+I on a Mac).
  2. Open the command menu: Ctrl+Shift+P (⌘+Shift+P).
  3. Type screenshot and pick Capture full size screenshot. A PNG of the whole page is downloaded.

For a phone-sized capture, switch on the device toolbar (Ctrl+Shift+M) first. Capture node screenshot captures just the element selected in the Elements panel.

2. Firefox: built in

Right-click an empty part of the page → Take Screenshot (or Ctrl+Shift+S) → Save full page. You can also drag to capture a region, then copy or download.

Why parts of the page come out wrong

  • Images missing further down: lazy-loaded images only load when scrolled into view. Scroll to the bottom once, then capture.
  • A header repeated or a banner covering content: sticky headers and cookie banners. Accept or close the banner first.
  • Only one section captured: the page scrolls inside an inner element instead of the window. Use Capture node screenshot on that element.

3. Command line: Playwright

npx playwright install chromium
npx playwright screenshot --full-page https://en.wikipedia.org/wiki/Markdown page.png
npx playwright screenshot --full-page --device "Pixel 5" https://example.com mobile.png

iPhone device profiles run in WebKit, so they need npx playwright install webkit first. Add --wait-for-timeout 3000 for pages that keep loading after the first paint. Loop over a list of URLs in a shell script for small batches.

Frequently asked questions

How do I take a full-page screenshot in Chrome without an extension?

DevTools → command menu (Ctrl+Shift+P) → Capture full size screenshot.

Can I save a full web page as PDF instead?

Yes: Ctrl+P → Save as PDF. The PDF uses print styles and splits into pages; a screenshot shows the page exactly as on screen in one image.

Why is my full-page screenshot blank at the bottom?

Lazy-loaded images and content weren't loaded yet. Scroll to the end of the page first, or add a wait on the command line.

How do I screenshot a page on iPhone?

Take a screenshot in Safari, tap the preview and choose Full Page. That saves the whole page as a PDF.
