How to export an HTML table to Excel with JavaScript

Two ways to let visitors download a table from your page: a small CSV function with no library, or a real .xlsx file with SheetJS.

1. CSV, no library

function downloadTableAsCsv(table, filename = 'table.csv') {
  const quote = text => {
    text = text.replace(/\s+/g, ' ').trim();
    if (/^[=+\-@]/.test(text)) text = "'" + text; // stop Excel from running cell text as a formula
    return /[",\n]/.test(text) ? '"' + text.replace(/"/g, '""') + '"' : text;
  };
  const rows = [...table.rows].map(row => [...row.cells].map(cell => quote(cell.innerText)).join(','));
  const blob = new Blob(['﻿' + rows.join('\r\n')], { type: 'text/csv;charset=utf-8' }); // BOM: Excel reads UTF-8
  const a = document.createElement('a');
  a.href = URL.createObjectURL(blob);
  a.download = filename;
  a.click();
  URL.revokeObjectURL(a.href);
}

Call it from a button: downloadTableAsCsv(document.querySelector('#my-table'), 'report.csv'). What each part does, checked on our test table:

  • The BOM (\uFEFF) marks the file as UTF-8. With it, Zoë Müller, São Paulo and 李雷 opened correctly.
  • Quoting: cells with commas, quotes or line breaks are wrapped in quotes and inner quotes doubled ("says ""hi"""), so Ana, Jr. stayed in one cell.
  • Formula guard: a cell starting with =, +, - or @ gets a leading apostrophe. Otherwise =1+1 from your page could run as a formula in the user's spreadsheet (CSV injection). The trade-off: LibreOffice displayed '=1+1 with the apostrophe, and negative numbers like -5 also become text. Drop - from the pattern if your table has negative numbers and no user-entered text.
  • Whitespace: innerText is used and runs of whitespace are collapsed, so a <br> becomes a space.

The catch: a CSV has no types, so the spreadsheet guesses. LibreOffice turned the ID 0042 into 42 and 1,234.50 into the number 1234.5 (in an English locale). If that matters, use .xlsx.

2. A real .xlsx with SheetJS

<script src="https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js"></script>
<script>
function downloadTableAsXlsx(table, filename = 'table.xlsx') {
  const workbook = XLSX.utils.table_to_book(table, { raw: true });
  XLSX.writeFile(workbook, filename);
}
</script>

SheetJS reads the table and writes an Excel workbook in the browser, with no server involved. Our results:

Use the default when the table holds real numbers you want to add up, and raw: true when it holds IDs, phone numbers or codes. The library file is about 950 KB, so load it only on pages that need it. Pin the version you tested, and get it from SheetJS's own CDN (cdn.sheetjs.com): the xlsx package on the npm registry is an old version.

Which one?

CSV for small tables and minimal code; .xlsx when the data has leading zeros, long numbers or line breaks, or when users expect a "real" Excel file. To convert a table once, without writing code, paste it into the free HTML table to CSV converter.

Frequently asked questions

Why does Excel show strange characters in my CSV?

The file is UTF-8 without a BOM, so the spreadsheet guesses another encoding. Start the file with \uFEFF, as in the code above. With it, accented and Chinese text opened correctly in our test.

How do I keep leading zeros when exporting to Excel?

CSV can't: the spreadsheet decides the type when it opens the file (0042 became 42 in our test). Export .xlsx with SheetJS and { raw: true }, which stores the cell as text.

Can I export a table with formatting (colors, bold)?

Not with these methods: both export values only. According to its documentation, the free SheetJS edition doesn't write cell styles.

Does this send the data to a server?

No. Both methods build the file in the browser and download it directly.
