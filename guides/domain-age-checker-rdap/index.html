How to check a domain's age and expiry date (free WHOIS / RDAP API)

RDAP is the free, JSON-based replacement for WHOIS. One request tells you a domain's registration date, expiry date and registrar.

1. One domain with curl

curl -sL https://rdap.org/domain/github.com

rdap.org redirects to the registry responsible for the domain's TLD. In the JSON, events holds the dates: registration (github.com: 2007-10-09, so the domain age), expiration and last changed. The registrar is the entity with the role registrar.

2. Python, for a list of domains

import json, urllib.request

for domain in ["github.com", "bbc.co.uk", "example.de"]:
    try:
        data = json.load(urllib.request.urlopen(f"https://rdap.org/domain/{domain}", timeout=15))
    except Exception as e:
        print(domain, "no RDAP data:", e)
        continue
    events = {e["eventAction"]: e["eventDate"] for e in data.get("events", [])}
    print(domain, "registered", events.get("registration"), "expires", events.get("expiration"))

Go slowly on long lists: registries rate-limit RDAP, and some answer HTTP 429 after a few dozen quick requests.

Where dates are missing

  • Some country TLDs publish no RDAP or no dates. For example.de the request above returns 404: DENIC (.de) does not publish registration dates at all. Several other ccTLDs only offer port-43 WHOIS with their own text format.
  • Registrant names are usually redacted since GDPR. Age, expiry, registrar and name servers are still public.
  • "Registration" is the current registration. A domain that expired and was re-registered shows the new date; for its earlier history you need archive sources such as the Wayback Machine.

Domain age vs SSL certificate expiry

The domain's expiry date is not the certificate's. Check certificates with the SSL expiry guide.

Frequently asked questions

How do I check how old a domain is?

Look up its RDAP record (https://rdap.org/domain/example.com) and read the registration event. WHOIS shows the same date as 'Creation Date'.

Is WHOIS being replaced?

Yes. ICANN made RDAP the required lookup service for generic TLDs (.com, .net, .org …) in 2025. Many country TLDs still only run WHOIS.

Why can't I see the owner of a domain?

Since GDPR most registrars redact personal registrant data. You can usually contact the owner through the registrar's anonymized email or web form.

Why does a .de domain show no creation date?

DENIC, the .de registry, does not publish registration or expiry dates, so no tool can show them.
