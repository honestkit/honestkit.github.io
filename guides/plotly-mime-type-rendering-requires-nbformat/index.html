Plotly ValueError: Mime type rendering requires nbformat>=4.2.0 (tested)

ValueError: Mime type rendering requires nbformat>=4.2.0 but it is not installed from fig.show() means Jupyter/VS Code rendering needs the nbformat package, which pip install plotly does not pull in. Run %pip install "nbformat>=4.2.0" in the notebook, then restart the kernel: installing it into a running kernel is not enough.

1. Reproduce it

b2.py (outside Jupyter we replace IPython.display.display with a stub that prints which MIME types would be sent to the notebook, instead of dumping the whole figure):

import IPython.display
# outside Jupyter, print which MIME bundle would be sent instead of dumping it
IPython.display.display = lambda obj, raw=False, **kw: print("  displayed:", sorted(obj))
import plotly.express as px
fig = px.line(x=[1, 2, 3], y=[4, 1, 6])
for r in ["plotly_mimetype", "vscode", "colab"]:
    try:
        fig.show(renderer=r)
        print(f"{r}: OK")
    except ValueError as ex:
        print(f"{r}: ValueError: {ex}")

Fresh venv, plotly 7.1.0, ipython 9.17.1, Python 3.13.5:

$ pip install -q plotly pandas ipython
$ python b2.py
plotly_mimetype: ValueError: Mime type rendering requires nbformat>=4.2.0 but it is not installed
vscode: ValueError: Mime type rendering requires nbformat>=4.2.0 but it is not installed
colab: ValueError: Mime type rendering requires nbformat>=4.2.0 but it is not installed
$ pip install -q "nbformat>=4.2.0"
$ python b2.py
  displayed: ['application/vnd.plotly.v1+json']
plotly_mimetype: OK
  displayed: ['application/vnd.plotly.v1+json']

  displayed: ['text/html']

  • plotly does not depend on nbformat, so pip install plotly (even together with pandas and ipython) leaves it out. Every notebook-style renderer (plotly_mimetype, vscode, colab, ...) then raises ValueError: Mime type rendering requires nbformat>=4.2.0 but it is not installed.
  • After pip install "nbformat>=4.2.0" the same script displays the figure (installed: nbformat 5.11.1).
  • Without ipython at all, the message is different: Mime type rendering requires ipython but it is not installed (and The NotebookRenderer class requires ipython for renderer="notebook").

2. Installed nbformat and it still fails? Restart the kernel

b4.py installs nbformat into its own environment while running:

import IPython.display, subprocess, sys
IPython.display.display = lambda obj, raw=False, **kw: print("  displayed:", sorted(obj))
import plotly.express as px
fig = px.line(x=[1, 2, 3], y=[4, 1, 6])
def show():
    try:
        fig.show(renderer="plotly_mimetype"); print("show: OK")
    except ValueError as ex:
        print("show: ValueError:", ex)
show()
subprocess.run([sys.executable, "-m", "pip", "install", "-q", "nbformat>=4.2.0"], check=True)
print("installed nbformat in the running process's environment")
show()
show: ValueError: Mime type rendering requires nbformat>=4.2.0 but it is not installed
installed nbformat in the running process's environment
show: ValueError: Mime type rendering requires nbformat>=4.2.0 but it is not installed
  • Installing nbformat into a running Python process does not fix it: the second show() fails with the same error. In Jupyter, run %pip install "nbformat>=4.2.0" in a cell (it installs into the kernel's environment, unlike a bare !pip that may hit another Python), then restart the kernel and re-run.
  • If it still fails after a restart, the kernel is using a different environment than the one you installed into: compare import sys; sys.executable in the notebook with the pip you used.

3. Without nbformat: write_html works, iframe/json do not

import IPython.display
IPython.display.display = lambda obj, raw=False, **kw: print("  displayed:", sorted(obj) if isinstance(obj, dict) else type(obj).__name__)
import plotly.express as px, plotly.io as pio, os
fig = px.line(x=[1, 2, 3], y=[4, 1, 6])
fig.write_html("fig.html")
print("write_html: OK,", os.path.getsize("fig.html") // 1024, "KiB")
for r in ["iframe", "json"]:
    try:
        fig.show(renderer=r)
        print(f"{r}: OK")
    except ValueError as ex:
        print(f"{r}: ValueError: {ex}")
write_html: OK, 4710 KiB
iframe: ValueError: Mime type rendering requires nbformat>=4.2.0 but it is not installed
json: ValueError: Mime type rendering requires nbformat>=4.2.0 but it is not installed
  • fig.write_html() needs neither ipython nor nbformat; open the file in a browser. Outside notebooks, fig.show() defaults to the browser renderer.
  • The iframe and json renderers also go through the MIME path and raise the same nbformat error, so switching renderers is not a workaround inside Jupyter: install nbformat.

Frequently asked questions

How do I fix Mime type rendering requires nbformat>=4.2.0?

Run %pip install "nbformat>=4.2.0" in the notebook, then restart the kernel and re-run the cell.

I installed nbformat but plotly still shows the error. Why?

The kernel was not restarted, or nbformat went into a different environment than the kernel uses (check sys.executable).

Can I show a plotly figure without nbformat?

Yes, with fig.write_html("fig.html") and opening the file in a browser. The iframe and json renderers still need nbformat.
