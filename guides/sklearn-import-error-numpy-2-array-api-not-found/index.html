import sklearn: _ARRAY_API not found with NumPy 2 (tested)

import sklearn under NumPy 2 can fail with AttributeError: _ARRAY_API not found and ImportError: numpy.core.multiarray failed to import. With scikit-learn 1.3.2 the module that actually breaks is SciPy 1.11.4. Pin numpy<2 or upgrade both; tested below.

1. Reproduce: scikit-learn 1.3.2 with NumPy 2

A Python 3.11 venv with scikit-learn==1.3.2 and scipy==1.11.4, then numpy==2.2.6 installed afterwards (installing all three in one command is refused by the resolver, because scikit-learn 1.3.2 requires numpy<2.0). b1.py:

import numpy
print("numpy", numpy.__version__)
import sklearn
print("sklearn", sklearn.__version__)
from sklearn.linear_model import LinearRegression
print(LinearRegression().fit([[0], [1]], [0, 2]).coef_)

2. What it means

  • import sklearn fails, but the module that breaks is SciPy: the stack goes sklearn/utils/__init__.py → scipy/sparse/_csr.py. SciPy 1.11.4 was compiled for NumPy 1.x and fails with AttributeError: _ARRAY_API not found, then ImportError: numpy.core.multiarray failed to import.
  • pip check names both culprits: scipy 1.11.4 requires numpy<1.28.0, scikit-learn 1.3.2 requires numpy<2.0.

3. Fix: pin numpy<2, or upgrade scikit-learn and SciPy together

$ pip install "numpy<2"
$ python b1.py
numpy 1.26.4
sklearn 1.3.2
[2.]
$ pip install -U scikit-learn scipy numpy
$ python b1.py
numpy 2.4.6
sklearn 1.9.1
[2.]

Upgrade SciPy along with scikit-learn: upgrading only scikit-learn can leave the old SciPy in place (SciPy 1.13.0 is the first that allows NumPy 2; see SciPy NumPy 2 compatibility). Frequently asked questions

Why does import sklearn fail with _ARRAY_API not found?

An old scikit-learn/SciPy built for NumPy 1.x is installed alongside NumPy 2; in this test the import broke inside scipy.sparse.

How do I fix it?

pip install "numpy<2", or pip install -U scikit-learn scipy numpy (scikit-learn 1.9.1 ran on numpy 2.4.6 here).
