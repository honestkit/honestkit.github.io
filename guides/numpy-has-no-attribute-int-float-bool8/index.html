module 'numpy' has no attribute 'int' / 'float' / 'bool8' / 'float_'

AttributeError: module 'numpy' has no attribute 'int' (or 'float', 'bool8', 'float_', 'NaN') means your code or a library uses an alias NumPy removed: the builtin aliases in 1.24, the rest in 2.0. Use int/float or np.int64/np.float64, np.nan, np.prod. Tested on NumPy 1.26.4 and 2.3.4.

1. Which np.* names exist on NumPy 1.26 vs 2.x

import numpy as np
print(np.__version__)
for name in ["int", "float", "bool", "object", "str", "long", "bool8", "float_", "trapz", "product", "NaN", "Inf"]:
    try:
        getattr(np, name)
        print(f"np.{name}: ok")

Three different stories hide behind the same AttributeError. np.int, np.float, np.object and np.str were aliases for the Python builtins, removed in NumPy 1.24, and fail on both versions. np.float_, np.NaN, np.Inf, np.bool8 and np.product still worked on 1.26.4 and were removed in 2.0. And np.bool and np.long went the other way: missing on 1.26.4, back on 2.3.4 as NumPy scalar types (the FutureWarnings above). So the same script can fail on old NumPy and work on new, or the reverse. np.trapz still worked on 2.3.4 here; its new name is np.trapezoid (2.0+).

2. Replacements that work on both

import numpy as np
a = np.array([1.5, 2.5])
print(a.astype(int).dtype, a.astype(float).dtype, np.array([1, 0]).astype(bool).dtype)
print(np.int64, np.float64, np.bool_, np.nan, np.inf)
print(np.trapezoid([1, 2, 3]) if hasattr(np, "trapezoid") else "no trapezoid", np.prod([2, 3]))

Use the builtin (int, float, bool, object, str) or an explicit NumPy type (np.int64, np.float64, np.bool_); np.nan and np.inf in lower case; np.prod for np.product. np.trapezoid only exists from NumPy 2.0, so if you must support 1.x, use getattr(np, "trapezoid", None) or np.trapz. If the error comes from a library rather than your code (an old scikit-learn, bottleneck or numba calling np.float), upgrade that library or pin numpy<1.24; mismatched compiled extensions give a different error, covered in _ARRAY_API not found / dtype size changed.

Frequently asked questions

What do I replace np.int and np.float with?

The Python builtins int and float, or explicit sized types np.int64 and np.float64. Both work on NumPy 1.x and 2.x.

Why does np.bool work on NumPy 2 but not 1.26?

np.bool was a builtin alias removed in 1.24; NumPy 2 re-added np.bool as the NumPy boolean scalar type. In our test 1.26.4 raised and 2.3.4 worked (with a FutureWarning on access). np.long behaved the same.

The error comes from a library, not my code. What do I do?

Upgrade the library to a release that supports your NumPy version, or pin numpy<1.24 (for np.int/np.float) or numpy<2 (for np.float_, np.NaN) until it does.
