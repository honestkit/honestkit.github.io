ComfyUI-Manager: No module named 'toml' (IMPORT FAILED fix)

Cannot import .../ComfyUI-Manager module for custom nodes: No module named 'toml' means Manager's automatic dependency install failed. We reproduced it with ComfyUI v0.37.0 and Manager V3.42 and fixed it.

1. The error

We started ComfyUI v0.37.0 with ComfyUI-Manager V3.42 in custom_nodes and the toml package uninstalled. Manager's prestartup script checks its own dependencies and normally installs a missing toml by itself: with network access it printed + toml==0.10.2 and loaded fine. The error only appears when that automatic install fails. We made the package index unreachable to reproduce it:

ComfyUI still exited 0 (other nodes loaded), so the only visible symptom is the missing Manager button. glob/manager_core.py line 26 imports toml, which is listed in Manager's own requirements.txt (not ComfyUI's).

2. Fix: install Manager's requirements.txt with ComfyUI's Python

From the ComfyUI folder, using the Python that starts ComfyUI (your venv's python; in the Windows portable build, ..\python_embeded\python.exe run from inside the ComfyUI folder):

python -m pip install -r custom_nodes/ComfyUI-Manager/requirements.txt
Collecting toml (from -r custom_nodes/ComfyUI-Manager/requirements.txt (line 9))
  Downloading toml-0.10.2-py2.py3-none-any.whl.metadata (7.1 kB)
Downloading toml-0.10.2-py2.py3-none-any.whl (16 kB)
Installing collected packages: toml
Successfully installed toml-0.10.2

On the next start, Manager loaded with no IMPORT FAILED:

[INFO]    0.0 seconds: /path/to/ComfyUI/custom_nodes/ComfyUI-Manager

If the automatic install failed for you, fix the reason too (no network, a proxy, or a Python without pip), or Manager will hit the same wall for its other dependencies. The second message above (pip's --user is unsupported) came from Manager's fallback attempt and is harmless inside a venv.

If pip says toml is already installed and the error stays, you are installing into a different Python than the one running ComfyUI. See ComfyUI: No module named 'yaml' for how to find the right one.

Frequently asked questions

Why does ComfyUI-Manager need toml?

glob/manager_core.py imports it at load time and it is in Manager's requirements.txt. Without it, Manager shows IMPORT FAILED and its menu button is missing.

Doesn't Manager install its dependencies itself?

It tries at startup (we saw it install toml 0.10.2 when the network worked). The error appears only when that install fails, e.g. offline or with a broken pip.
