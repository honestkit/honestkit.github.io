ComfyUI-Manager cm-cli: ModuleNotFoundError: No module named 'utils' (fix)

ModuleNotFoundError: No module named 'utils' from ComfyUI-Manager's cm-cli.py means it could not find your ComfyUI folder. We reproduced it with a Manager clone outside custom_nodes and fixed it two ways, plus the related 'utils.extra_config' variant.

1. The error

The git-clone version of ComfyUI-Manager (commit 7e1af9c here) ships cm-cli.py. Run from a Manager folder that is not inside ComfyUI/custom_nodes/, without COMFYUI_PATH set:

python /path/to/ComfyUI-Manager/cm-cli.py show installed
WARN: The `COMFYUI_PATH` environment variable is not set. Assuming 
`custom_nodes/ComfyUI-Manager/../../` as the ComfyUI path.
Traceback (most recent call last):
  File "/path/to/ComfyUI-Manager/cm-cli.py", line 38, in <module>
    import utils.extra_config
ModuleNotFoundError: No module named 'utils'

Line 38 is import utils.extra_config. That utils is not a pip package: it is the utils/ folder inside your ComfyUI checkout (next to main.py). cm-cli.py works out where ComfyUI is in this order: the COMFYUI_PATH environment variable, then an importable folder_paths, then a guess of two folders above itself (custom_nodes/ComfyUI-Manager/../../). It appends that path to sys.path. When Manager is cloned anywhere else the guess points at the wrong folder, so the import fails right after the WARN line.

2. Fix: set COMFYUI_PATH

Point it at the folder that contains main.py, and run it with the same Python (venv) that runs ComfyUI:

COMFYUI_PATH=/path/to/ComfyUI python /path/to/ComfyUI-Manager/cm-cli.py show installed
Cannot connect to comfyregistry.
FETCH DATA from: /path/to/ComfyUI/user/__manager/cache/1514988643_custom-node-list.json [DONE]

4. No module named 'utils.extra_config'

A different message means a different cause. cm-cli.py appends the ComfyUI path to sys.path, so site-packages are searched first. If an unrelated package named utils is installed in that venv (we installed utils 1.0.2 from PyPI), it wins even with COMFYUI_PATH set correctly:

Traceback (most recent call last):
  File "/path/to/ComfyUI-Manager/cm-cli.py", line 38, in <module>
    import utils.extra_config
ModuleNotFoundError: No module named 'utils.extra_config'

Check with python -c "import utils; print(utils.__file__)": if the path is in site-packages instead of your ComfyUI folder, remove that package:

python -m pip uninstall utils

After uninstalling it, the same COMFYUI_PATH=... cm-cli.py show installed listed all four node packs again.

Frequently asked questions

Can I pip install utils to fix cm-cli?

No. The utils it needs is the utils/ folder inside ComfyUI. Installing the PyPI utils package makes it worse: cm-cli then fails with No module named 'utils.extra_config'.

Where should COMFYUI_PATH point?

At the ComfyUI folder that contains main.py (and the utils/ and custom_nodes/ folders).
