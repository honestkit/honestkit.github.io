statsmodels and NumPy 2 compatibility (tested)

statsmodels 0.14.1 and older fail at import statsmodels.api under NumPy 2 with ValueError: numpy.dtype size changed, may indicate binary incompatibility. 0.14.2 is the first release that supports NumPy 2; newer SciPy and pandas 3 then break older 0.14.x in two more ways. Tested below.

1. Reproduce: statsmodels 0.14.1 with NumPy 2

A Python 3.11 venv with statsmodels==0.14.1, then numpy==2.2.6, scipy==1.15.3 and pandas==2.2.3 installed in a second command. Asking for both at once is refused:

error: No solution found when resolving dependencies
  cause: Because statsmodels==0.14.1 depends on numpy>=1.18,<2 and you require statsmodels==0.14.1, we can conclude that you require numpy>=1.18,<2.
         And because you require numpy==2.2.6, we can conclude that your requirements are unsatisfiable.

b1.py:

import numpy
print("numpy", numpy.__version__)
import statsmodels.api as sm
print("statsmodels", sm.__version__)
x = sm.add_constant(numpy.arange(10.0))
y = 2 * numpy.arange(10.0) + 1
print(sm.OLS(y, x).fit().params.round(3))

Output, exit code 1 (paths shortened to /venv):

It fails at import statsmodels.api, in the compiled _smoothers_lowess extension, built against NumPy 1.x. statsmodels 0.14.0 gives the same numpy.dtype size changed error with NumPy 2, and its metadata has no numpy<2 cap, so pip installs NumPy 2 next to it without complaint.

2. Which statsmodels version supports NumPy 2

PyPI metadata: 0.14.0 numpy>=1.18 (uncapped, but broken on NumPy 2); 0.14.1 numpy<2,>=1.18; 0.14.2 numpy>=1.22.3. statsmodels 0.14.2 is the first release that works with NumPy 2; with numpy 2.2.6, scipy 1.15.3 and pandas 2.3.3 it ran b1.py:

numpy 2.2.6
statsmodels 0.14.2
[1. 2.]

3. Fix: pin numpy<2, or upgrade statsmodels

$ pip install "numpy<2"
$ python b1.py
numpy 1.26.4
statsmodels 0.14.1
[1. 2.]
$ pip install -U statsmodels scipy pandas numpy
$ python b1.py
numpy 2.4.6
statsmodels 0.15.0
[1. 2.]

On Python 3.11 the upgrade resolved to statsmodels 0.15.0, NumPy 2.4.6, SciPy 1.17.1 and pandas 3.1.0. Upgrade all four together: a partial upgrade hits the two errors below.

Which statsmodels version supports NumPy 2?

statsmodels 0.14.2: it dropped the numpy<2 cap and ran with numpy 2.2.6 in this test. 0.14.0 and 0.14.1 failed with numpy.dtype size changed.

How do I fix cannot import name '_lazywhere' from 'scipy._lib._util'?

Upgrade statsmodels (0.14.5 worked with SciPy 1.17.1), or pin scipy<1.16 for older statsmodels.

statsmodels 0.14.x with pandas 3. Upgrade to statsmodels 0.15.0 or pin pandas<3.
