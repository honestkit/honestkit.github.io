How to extract all links from a web page

Five ways to pull every link out of a page, from a one-line console snippet to crawling a whole site.

1. Browser console (no install, one page)

Open DevTools (F12) → Console, paste this and press Enter:

copy([...new Set([...document.links].map(a => a.href.split('#')[0]))].join('\n'))

Every unique link on the page, already made absolute, is now on your clipboard, one per line. copy() is a DevTools helper available in Chrome, Edge and Firefox. Chrome may ask you to type allow pasting the first time you paste into the console. That warning is there because pasted code runs with full access to the page, so only paste code you understand.

2. A link-extractor extension (filters and Excel export)

PlainLinks (ours, free) lists every link on the page or in your selection, removes duplicates and lets you filter by text, domain, file type (PDFs, documents, images) or a regular expression. Copy the URLs or a Markdown list, or export CSV / Excel with the anchor text, rel (nofollow) and internal/external columns. It reads the page only when you click its button.

3. Online, from HTML you already have

Paste page source or an HTML snippet into the free link extractor. Add the page's URL as the base so relative links like /about become absolute. It runs in your browser.

4. Python: requests + BeautifulSoup

from urllib.parse import urljoin
import requests
from bs4 import BeautifulSoup

url = "https://en.wikipedia.org/wiki/Markdown"
html = requests.get(url, headers={"User-Agent": "link-script/1.0 (you@example.com)"}, timeout=30).text
links = {urljoin(url, a["href"]).split("#")[0] for a in BeautifulSoup(html, "html.parser").find_all("a", href=True)}
print("\n".join(sorted(links)))

urljoin turns relative links into absolute ones, and the set removes duplicates. Set a descriptive User-Agent: some sites, Wikipedia included, reject the default one. This only sees links in the HTML the server sends. Links added by JavaScript need a real browser (methods 1 and 2).

5. A quick shell one-liner (rough)

curl -s https://example.com | grep -oE 'href="[^"]+"' | sed 's/^href="//; s/"$//' | sort -u

Good for a quick look, but it also catches stylesheets and icons, leaves relative links relative, and misses single-quoted or unquoted attributes.

Frequently asked questions

How do I extract only PDF links?

In the console: add .filter(u => u.endsWith('.pdf')) before .join. In PlainLinks: use the documents filter or the regular expression /\.pdf$/.

Why are some links missing?

Links inside iframes from other sites, links created only on click, and menus loaded later are not in the page yet. Scroll or open the menu first, then extract.

Can I get the anchor text too?

Yes: PlainLinks exports URL and anchor text columns to CSV or Excel. In Python use a.get_text(strip=True) next to the href.

How do I extract links from many pages?

Loop over URLs with the Python snippet, or use a crawler for a whole site.
