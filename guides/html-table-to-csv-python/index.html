How to convert an HTML table to CSV in Python

pandas.read_html is the usual answer, but it needs pandas plus lxml or BeautifulSoup. This script uses only Python's standard library, so it runs anywhere Python 3 does.

1. The script

Save as table2csv.py:

import csv, sys, urllib.request
from html.parser import HTMLParser

class Tables(HTMLParser):
    # Collects every top-level <table> as a list of rows (text only; colspan repeats the cell)
    def __init__(self):
        super().__init__(); self.tables = []; self.row = None; self.cell = None; self.span = 1; self.depth = 0
    def handle_starttag(self, tag, attrs):
        if tag == 'table': self.depth += 1; self.tables.append([]) if self.depth == 1 else None
        elif self.depth == 1 and tag == 'tr': self.row = []
        elif self.depth == 1 and tag in ('td', 'th') and self.row is not None:
            self.cell = []; self.span = int(dict(attrs).get('colspan') or 1)
        elif tag == 'br' and self.cell is not None: self.cell.append(' ')
    def handle_endtag(self, tag):
        if tag == 'table': self.depth -= 1
        elif self.depth == 1 and tag in ('td', 'th') and self.cell is not None:
            self.row += [' '.join(''.join(self.cell).split())] * self.span; self.cell = None
        elif self.depth == 1 and tag == 'tr' and self.row is not None:
            if self.row: self.tables[-1].append(self.row)
            self.row = None
    def handle_data(self, data):
        if self.cell is not None: self.cell.append(data)

url, index = sys.argv[1], int(sys.argv[2]) if len(sys.argv) > 2 else 0
req = urllib.request.Request(url, headers={'User-Agent': 'Mozilla/5.0 (table2csv)'})
p = Tables(); p.feed(urllib.request.urlopen(req).read().decode('utf-8', 'replace'))
print(f'{len(p.tables)} tables; sizes: {[len(t) for t in p.tables][:10]}', file=sys.stderr)
csv.writer(sys.stdout).writerows(p.tables[index])

2. Run it

python3 table2csv.py https://en.wikipedia.org/wiki/List_of_sovereign_states_and_dependencies_by_area 1 > countries.csv

3. Limits

  • rowspan is not expanded: a cell that spans several rows appears only in its first row, so later cells shift left. colspan is repeated. If your table uses rowspan, paste its HTML into the free HTML table to CSV tool, which expands both.
  • Only the server HTML: tables built by JavaScript after the page loads are not in the downloaded HTML. For those, use the browser extension below.
  • Nested tables are skipped (only top-level tables are collected).

Frequently asked questions

Does this need pandas?

No. It uses only html.parser, csv and urllib from the standard library. If you already use pandas, pandas.read_html is the common alternative (it needs lxml or BeautifulSoup too).

Why does it find no tables?

The table is probably built by JavaScript, or the site blocks scripts. Check by viewing the page source (not the inspector): if the table is not there, the script cannot see it.
