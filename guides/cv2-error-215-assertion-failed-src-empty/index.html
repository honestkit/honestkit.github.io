cv2.error (-215:Assertion failed) !_src.empty() (tested)

(-215:Assertion failed) !_src.empty() in function 'cvtColor' (or !ssize.empty() in resize) means the image you passed is empty, almost always because cv2.imread() returned None for a wrong path. imread does not raise; check if img is None right after it.

1. Reproduce it

b1.py:

import cv2, numpy as np

def attempt(label, fn):
    try:
        fn()
        print(f"{label}: OK")
    except cv2.error as ex:
        print(f"{label}:")
        for l in str(ex).splitlines():
            if l.strip():
                print("  " + l.strip())

img = cv2.imread("missing.jpg")              # wrong path: no exception, just None
print("cv2.imread('missing.jpg') ->", img)

attempt("cvtColor(None)", lambda: cv2.cvtColor(img, cv2.COLOR_BGR2GRAY))
attempt("resize(None)", lambda: cv2.resize(img, (100, 100)))
empty = np.zeros((0, 0, 3), np.uint8)
attempt("resize(empty array)", lambda: cv2.resize(empty, (100, 100)))
gray = np.zeros((50, 50), np.uint8)
attempt("cvtColor(gray, BGR2GRAY)", lambda: cv2.cvtColor(gray, cv2.COLOR_BGR2GRAY))
f64 = np.zeros((50, 50, 3), np.float64)
attempt("cvtColor(float64 image)", lambda: cv2.cvtColor(f64, cv2.COLOR_BGR2GRAY))

  • cv2.imread() does not raise on a wrong path: it prints a [ WARN ] line and returns None. The crash only comes at the next call, as (-215:Assertion failed) !_src.empty() in cvtColor or !ssize.empty() in resize.
  • A zero-size numpy array (e.g. an empty crop like img[y:y, x:x]) gives the same !ssize.empty() error.
  • Passing a 1-channel image to COLOR_BGR2GRAY is a different error, (-15:Bad number of channels) with 'scn' is 1; a float64 image gives Unsupported depth with 'depth' is 6 (CV_64F).

2. The fix: check what imread returned

import cv2, numpy as np
from pathlib import Path

def load(path):
    img = cv2.imread(str(path))
    if img is None:
        raise FileNotFoundError(f"cv2.imread could not read {Path(path).resolve()}")
    return img

cv2.imwrite("ok.png", np.full((20, 30, 3), 255, np.uint8))
img = load("ok.png")
print("shape", img.shape, "dtype", img.dtype)
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) if img.ndim == 3 else img
print("gray", gray.shape)
f64 = np.zeros((50, 50, 3), np.float64)
print("float64 -> float32:", cv2.cvtColor(f64.astype(np.float32), cv2.COLOR_BGR2GRAY).dtype)
try:
    load("missing.jpg")
except FileNotFoundError as ex:
    print("FileNotFoundError:", ex)

  • Check for None right after imread and raise with the resolved path: most -215 errors are a relative path resolved against a different working directory than you expected.
  • Convert only 3-channel images (img.ndim == 3), and cast float64 to float32 (or uint8) before cvtColor.

Frequently asked questions

Why does cv2.imread return None?

The file could not be opened or decoded, usually a wrong or relative path. imread only prints a warning and returns None instead of raising.

What does !ssize.empty() in function resize mean?

cv2.resize got an empty image: None from imread, or a zero-size crop.

How do I fix Bad number of channels in cvtColor?

The image already has 1 channel; skip COLOR_BGR2GRAY when img.ndim == 2.
