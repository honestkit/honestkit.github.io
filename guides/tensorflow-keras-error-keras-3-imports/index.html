TensorFlow Keras errors after upgrading to Keras 3 (tested)

TensorFlow 2.16+ installs Keras 3, so Keras 2 code fails with No module named 'keras.layers.core', cannot import name 'adam', Argument(s) not recognized: {'lr': 0.01} or Invalid filepath extension for saving. Seven failures and their fixes, tested on TensorFlow 2.21.0 with Keras 3.15.1.

1. Reproduce: Keras 2 code on Keras 3

Since TensorFlow 2.16, pip install tensorflow brings Keras 3, which removed many Keras 2 module paths and arguments. b1.py runs seven common lines from older tutorials:

2. Fix: the Keras 3 spelling

import os; os.environ["TF_CPP_MIN_LOG_LEVEL"] = "3"
import keras
from keras.layers import Dense                    # was keras.layers.core
from keras.utils import to_categorical            # was keras.utils.np_utils
from keras.optimizers import Adam                 # class name is capitalised

opt = Adam(learning_rate=0.01)                    # lr= was removed
print("learning_rate:", float(opt.learning_rate))
print(to_categorical([0, 2], num_classes=3).tolist())

model = keras.Sequential([keras.Input((3,)), Dense(1)])
model.save("my_model.keras")                      # native format needs .keras
print("reloaded:", type(keras.models.load_model("my_model.keras")).__name__)

Frequently asked questions

Why do I get No module named keras.layers.core?

Keras 3 (installed by TensorFlow 2.16+) removed keras.layers.core. Import layers directly: from keras.layers import Dense.

Why does Adam(lr=0.01) fail?

Keras 3 removed the lr alias. Use Adam(learning_rate=0.01); the old call raises ValueError: Argument(s) not recognized.

Why does model.save fail with Invalid filepath extension?

Keras 3 needs a .keras (or .h5) extension. Use model.save("my_model.keras"), or model.export(path) for a TensorFlow SavedModel.
