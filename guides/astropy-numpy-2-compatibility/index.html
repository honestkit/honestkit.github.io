astropy and NumPy 2 compatibility (tested)

astropy 6.0.x fails under NumPy 2 with numpy.dtype size changed when you import astropy.table, time or coordinates. astropy 6.1 to 7.1 then fail under NumPy 2.4 with AttributeError: module 'numpy' has no attribute 'in1d'. astropy 7.2.0 works. Tested below.

1. Reproduce: astropy 6.0.1 with NumPy 2

A Python 3.11 venv with astropy==6.0.1 (which pins numpy<2, so it installs 1.26.4), then numpy==2.2.6 in a second command. b1.py:

import numpy
print("numpy", numpy.__version__)
import astropy
print("astropy", astropy.__version__)
from astropy import units as u
print((3 * u.km).to(u.m))
from astropy.table import Table
print(len(Table({"a": [1, 2, 3]})), "rows")

Output, exit code 1 (paths shortened):

$ python b1.py

astropy 6.0.1

import astropy and astropy.units still work, which is why this surprises people: only the compiled submodules fail. In the same venv, astropy.table and astropy.stats raised numpy.dtype size changed; astropy.wcs, astropy.time, astropy.coordinates and astropy.convolution raised ImportError: numpy.core.multiarray failed to import; astropy.io.fits imported fine.

NumPy 2.4 removed np.in1d (deprecated since 2.0 in favour of np.isin). With numpy 2.4.6: astropy 6.1.7, 7.0.2 and 7.1.1 fail the same way; astropy 7.2.0 works.

3. Fix: upgrade astropy, or pin NumPy

$ pip install -U astropy numpy
$ python b1.py
numpy 2.4.6
astropy 8.0.2
3000.0 m
3 rows

On Python 3.11 the upgrade resolved to astropy 8.0.2 with NumPy 2.4.6. To keep an older astropy, pin to what it was built for: numpy<2 for 6.0.x, numpy<2.4 for 6.1 to 7.1.

$ pip install "numpy<2"
$ python b1.py
numpy 1.26.4
astropy 6.0.1
3000.0 m
3 rows

Restart any Jupyter kernel after changing versions. Same problem elsewhere: SciPy, PyTables, Numba. All changes: NumPy 2 breaking changes.

Frequently asked questions

Which astropy version supports NumPy 2?

astropy 6.1.0 for NumPy 2.0 to 2.3; for NumPy 2.4, astropy 7.2.0 or newer (6.1.7, 7.0.2 and 7.1.1 failed with numpy 2.4.6).

How do I fix module 'numpy' has no attribute 'in1d' in astropy?

pip install -U astropy (7.2.0+), or pin numpy<2.4.
