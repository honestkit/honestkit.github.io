SciPy standard error: scipy.stats.sem, ddof, NaN and regression (tested)

scipy.stats.sem(x) returns the standard error of the mean, x.std(ddof=1) / sqrt(n). If your own number is smaller, you used np.std, which defaults to ddof=0. Below: NaN, axis, confidence intervals, and standard errors of regression coefficients, all measured.

1. scipy.stats.sem: ddof, NaN, axis

b1.py compares scipy.stats.sem with the manual formula and shows the three things that change its result:

import numpy as np
from scipy import stats

x = np.array([4.1, 5.0, 3.8, 6.2, 5.5, 4.9])
print("stats.sem(x)            ", stats.sem(x))
print("std(ddof=1)/sqrt(n)     ", x.std(ddof=1) / np.sqrt(len(x)))
print("np.std(x)/sqrt(n)       ", np.std(x) / np.sqrt(len(x)), "<- ddof=0, smaller")
print("stats.sem(x, ddof=0)    ", stats.sem(x, ddof=0))

y = np.array([4.1, np.nan, 3.8])
print("sem with NaN            ", stats.sem(y))
print("nan_policy='omit'       ", stats.sem(y, nan_policy="omit"))

m = np.array([[1.0, 2.0, 3.0], [2.0, 4.0, 9.0]])
print("2-D default axis=0      ", stats.sem(m))
print("axis=1                  ", stats.sem(m, axis=1))
print("axis=None               ", stats.sem(m, axis=None))
print("one value               ", stats.sem([5.0]))

  • stats.sem(x) is x.std(ddof=1) / sqrt(n): it uses the sample standard deviation (ddof=1) by default.
  • np.std defaults to ddof=0, so np.std(x)/np.sqrt(n) gives a smaller number (0.329 vs 0.361 here). That mismatch is the usual reason a hand-computed standard error disagrees with SciPy, pandas or a spreadsheet.
  • One NaN makes the result nan; nan_policy="omit" drops it.
  • On a 2-D array the default is axis=0 (one value per column); use axis=1 per row or axis=None for all values.
  • With a single value SciPy 1.18 returns nan and emits a SmallSampleWarning.

2. pandas .sem(), a 95% confidence interval, and regression standard errors

import numpy as np, pandas as pd
from scipy import stats
from scipy.optimize import curve_fit

x = np.array([4.1, 5.0, 3.8, 6.2, 5.5, 4.9])
print("pandas Series.sem()     ", pd.Series(x).sem())
print("pandas with NaN         ", pd.Series([4.1, np.nan, 3.8]).sem(), "<- skips NaN")

# 95% confidence interval for the mean from the SEM
lo, hi = stats.t.interval(0.95, df=len(x) - 1, loc=x.mean(), scale=stats.sem(x))
print("mean, 95% CI            ", round(x.mean(), 3), (float(round(lo, 3)), float(round(hi, 3))))

# standard error of a regression slope and intercept
t = np.array([0, 1, 2, 3, 4, 5.0])
y = np.array([1.1, 2.9, 5.2, 7.1, 8.8, 11.2])
res = stats.linregress(t, y)
print("linregress slope, stderr", round(res.slope, 4), round(res.stderr, 4))
print("intercept, stderr       ", round(res.intercept, 4), round(res.intercept_stderr, 4))

# standard errors of curve_fit parameters
popt, pcov = curve_fit(lambda t, a, b: a * t + b, t, y)
print("curve_fit perr          ", np.round(np.sqrt(np.diag(pcov)), 4))

Output:

  • pandas.Series.sem() matches scipy.stats.sem (also ddof=1) but skips NaN by default.
  • For a confidence interval of the mean, pass the SEM as scale to stats.t.interval with df=n-1.
  • stats.linregress returns the slope's standard error as stderr and the intercept's as intercept_stderr.
  • For curve_fit, the parameter standard errors are np.sqrt(np.diag(pcov)); for this straight line they match linregress exactly.

Frequently asked questions

How do I calculate standard error in SciPy?

scipy.stats.sem(x); it equals x.std(ddof=1) / sqrt(len(x)).

Why does np.std / sqrt(n) differ from scipy.stats.sem?

np.std uses ddof=0 by default while scipy.stats.sem uses ddof=1; pass ddof=1 to np.std or ddof=0 to sem to make them match.

How do I get the standard error of a regression slope in SciPy?

scipy.stats.linregress returns it as result.stderr, and the intercept's as result.intercept_stderr.
