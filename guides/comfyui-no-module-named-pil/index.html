ComfyUI: ModuleNotFoundError: No module named 'PIL' (fix)

ModuleNotFoundError: No module named 'PIL' stops ComfyUI at startup, before any model or custom node loads. We reproduced it on ComfyUI v0.37.0 and fixed it.

1. The error

ComfyUI v0.37.0 started in a venv where everything from requirements.txt is installed except Pillow:

python main.py
Traceback (most recent call last):
  File "/path/to/ComfyUI/main.py", line 35, in <module>
    from comfy_execution.progress import get_progress_state
  File "/path/to/ComfyUI/comfy_execution/progress.py", line 3, in <module>
    from PIL import Image
ModuleNotFoundError: No module named 'PIL'

ComfyUI exited with code 1 before loading any nodes: main.py line 35 imports comfy_execution/progress.py, which does from PIL import Image at line 3. PIL is the import name of the Pillow package, which is listed in ComfyUI's requirements.txt, so seeing it missing usually means the requirements were never installed into the Python that runs ComfyUI, or something uninstalled it.

2. Fix: install requirements.txt with the same Python

From the ComfyUI folder, using the Python that starts ComfyUI (your venv's python; in the Windows portable build, ..\python_embeded\python.exe run from inside the ComfyUI folder):

python -m pip install -r requirements.txt
Collecting Pillow (from -r requirements.txt (line 17))
  Downloading pillow-13.0.0-cp311-cp311-manylinux_2_27_x86_64.manylinux_2_28_x86_64.whl.metadata (9.1 kB)
Downloading pillow-13.0.0-cp311-cp311-manylinux_2_27_x86_64.manylinux_2_28_x86_64.whl (7.1 MB)

(pip also printed a dependency warning about an unrelated custom node package in our test venv; we left it out.) Started again, ComfyUI loaded all nodes and exited 0 (--quick-test-for-ci):

3. Don't run pip install PIL

The package name differs from the import name. Asking pip for PIL finds nothing:

python -m pip install PIL
ERROR: Could not find a version that satisfies the requirement PIL (from versions: none)
ERROR: No matching distribution found for PIL

Install Pillow (or the whole requirements.txt, as above) and keep importing it as PIL.

If pip says Pillow is already installed and the error stays, you are installing into a different Python than the one running ComfyUI. See ComfyUI: No module named 'yaml' for how to find the right one.

Frequently asked questions

Is Pillow required by ComfyUI?

Yes. Pillow is in requirements.txt and comfy_execution/progress.py imports it (as PIL) during startup, so ComfyUI exits with code 1 without it.

Why does pip install PIL fail?

PIL is only the import name. The package on PyPI is Pillow: run python -m pip install Pillow with the Python that starts ComfyUI.
