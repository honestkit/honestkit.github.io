How to extract text from PDFs (command line, Python and API)

Most PDFs already contain their text. Here is how to get it out, free, and what to do when a PDF is only a scanned image.

1. Command line: pdftotext (Poppler)

Install Poppler (apt install poppler-utils on Debian/Ubuntu, brew install poppler on macOS), then:

pdftotext report.pdf report.txt          # whole document
pdftotext -layout report.pdf -           # keep columns and tables aligned, print to the terminal
pdftotext -f 3 -l 5 report.pdf pages.txt # only pages 3 to 5
pdfinfo report.pdf                       # title, author, dates, page count

-layout keeps text in its visual position, which helps with tables and two-column layouts. Without it, text comes out in reading order, which is usually better for search or an LLM.

2. Python: pypdf

from pypdf import PdfReader   # pip install pypdf

reader = PdfReader("report.pdf")
print(len(reader.pages), reader.metadata)
text = "\n\n".join(page.extract_text() or "" for page in reader.pages)

pypdf is pure Python (no system packages), which makes it easy to use in serverless functions. For a PDF at a URL, download it first (urllib.request or requests) and pass the bytes in a BytesIO.

3. Scanned PDFs: you need OCR

If every tool above returns empty or near-empty text, the PDF is probably a scan: pictures of pages, no text layer. Extraction cannot help, only OCR (optical character recognition) can, for example Tesseract-based tools. A quick test: if you cannot select text in a PDF viewer, it is a scan.

Common problems

  • Words run together or break mid-word: the PDF positions single characters; try the other tool or -layout.
  • Headers and footers repeat on every page: extract page by page and drop lines that appear on most pages.
  • Garbled characters: the PDF uses fonts without a Unicode mapping; OCR is often the only fix.
  • Password-protected PDFs: pdftotext accepts -upw with the password; there is no honest way around it without one.

Frequently asked questions

What is the best free PDF to text converter?

pdftotext (Poppler) on the command line and pypdf in Python are both free and accurate for PDFs that contain text. Try both on a difficult file: they handle odd layouts differently.

Why is the extracted text empty?

The PDF is most likely a scan with no text layer. Use OCR.

How do I keep tables when converting a PDF to text?

Use pdftotext -layout to keep the columns aligned. For real table structure (rows and cells) you need a table-extraction tool, since plain text has no cells.

Is there a free PDF to text API?

You can wrap pdftotext or pypdf in a small function yourself. Hosted APIs save you the hosting and scaling; most, including ours, charge per document.
