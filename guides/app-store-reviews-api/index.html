How to get App Store reviews as JSON (API and export)

Apple publishes the most recent reviews of every iOS app as a public JSON feed. Here is how to use it, and where its limits are.

1. Find the app ID

It is the number after id in the App Store link, for example apps.apple.com/us/app/instagram/id389801252. Or search by name with Apple's public Search API:

curl "https://itunes.apple.com/search?term=instagram&entity=software&country=us&limit=5"

Each result has trackId (the app ID) and trackName. Check the name: search always returns a best guess, even for a misspelled or unknown app.

2. Read the reviews feed

curl "https://itunes.apple.com/us/rss/customerreviews/id=389801252/page=1/sortby=mostrecent/json"

feed.entry holds up to 50 reviews. Each has im:rating.label (1–5), title.label, content.label (the text), author.name.label, im:version.label (app version), updated.label (date) and im:voteSum / im:voteCount (helpful votes). Values are strings wrapped in {"label": …}.

  • Paging: page=1 to page=10, 50 reviews each. Page 11 returns an error.
  • Countries: replace us with another two-letter store code (gb, de, jp …). Every country is a separate list.
  • Sorting: sortby=mostrecent or sortby=mosthelpful.

The limits

  • At most 500 reviews per country per sort order (10 pages × 50). For popular apps that is only the last days or weeks. Collect regularly if you need history.
  • Only reviews with text appear. Star-only ratings are counted in the app's rating but never listed.
  • The feed is old and undocumented. Apple has not removed it, but there is no guarantee. It also often returns an empty page at random: retry with a fresh query string such as ?v=2 (see export App Store reviews to CSV for a script that does this).

Your own apps: App Store Connect API

For apps in your developer account, the official App Store Connect API has a customerReviews endpoint (per app, with your response to each review). It needs an API key from App Store Connect and only works for your own apps. Google Play is similar: its Developer API returns reviews of your own apps only (recent ones), and there is no public feed for other apps.

Frequently asked questions

Is there an official API for App Store reviews?

Only for your own apps (App Store Connect API). For any other app, the public customer-reviews feed shown above is what Apple provides.

How many reviews can I get?

Up to 500 per country per sort order from the public feed. Querying several countries adds more, since each store has its own reviews.

Can I export App Store reviews to CSV or Excel?

Convert the feed JSON with a script, paste it into the free JSON to CSV / Excel converter on this site, or use the Apify scraper, which outputs CSV and Excel directly.

Why do I see fewer reviews than the rating count?

Most ratings are stars without text. Only written reviews appear in the feed.
