So the order is: BOM, then the HTTP header, then the meta tag, then a locale default (windows-1252 here; iso-8859-1 is treated as windows-1252, which is why — becomes â€” and not three control characters). A missing charset is not "UTF-8 by default" for HTML or plain text.

The HTML spec only promises that a meta charset inside the first 1,024 bytes is found. Chromium 153 was more forgiving in our test: a meta after a 1,100-byte comment, after 100,000 bytes, and even inside <body> was still honored (served from localhost in a single write). Do not rely on that; put <meta charset="utf-8"> first in <head>.

fetch().text() and .json() always decode as UTF-8 and ignore the charset parameter. XHR follows the header, so an old jQuery or XHR client can garble a response that fetch reads fine. If you need another encoding with fetch, use new TextDecoder('windows-1252').decode(await res.arrayBuffer()).

Frequently asked questions

Why does é show as Ã© and — as â€”?

The bytes are UTF-8 but the client decoded them as windows-1252. In Chromium 153, text/html or text/plain without a charset and without a meta tag rendered café — as cafÃ© â€”.

Does the Content-Type header or the meta charset win?

The header. With Content-Type: text/html; charset=iso-8859-1 and <meta charset="utf-8"> in the page, Chromium 153 used windows-1252. Only a UTF-8 byte order mark at the start of the file overrode the header.

Is charset=utf-8 needed for application/json?

Not for browsers: Chromium showed JSON without a charset as UTF-8, and fetch().json() always decodes UTF-8. But a wrong charset such as iso-8859-1 garbled the page view and XMLHttpRequest.responseText.

Why does Python requests return garbled text?

For text/* responses without a charset, requests 2.32.3 set r.encoding to ISO-8859-1. Set r.encoding = 'utf-8' or r.apparent_encoding (which detected utf-8) before reading r.text.

How do I set charset=utf-8 in Node.js and Express?

In Node.js call res.setHeader('Content-Type', 'text/html; charset=utf-8'). Express 5.2.1 res.send, res.json, res.type and res.sendFile all added charset=utf-8 automatically, except when sending a Buffer.
