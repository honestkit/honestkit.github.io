How to get the color palette of any website

Two copy-paste snippets for the DevTools console: one lists the colors the page actually shows, the other the color variables the site defines.

1. The colors the page uses, most used first

Open the page, press F12 (or Cmd+Option+J on a Mac), go to Console, paste this and press Enter. Chrome may ask you to type "allow pasting" first.

(() => {
  const count = new Map();
  const hex = c => {
    const m = c.match(/^rgba?\((\d+), (\d+), (\d+)(?:, ([\d.]+))?\)$/);
    if (!m || m[4] === '0') return null; // skip transparent and non-sRGB colors
    return '#' + [m[1], m[2], m[3]].map(n => (+n).toString(16).padStart(2, '0')).join('');
  };
  for (const el of document.querySelectorAll('*')) {
    const s = getComputedStyle(el);
    if (s.display === 'none' || s.visibility === 'hidden') continue;
    for (const prop of ['color', 'background-color', 'border-top-color', 'fill']) {
      if (prop === 'border-top-color' && s.borderTopStyle === 'none') continue;
      const h = hex(s.getPropertyValue(prop));
      if (h) count.set(h, (count.get(h) || 0) + 1);
    }
  }
  const palette = [...count].sort((a, b) => b[1] - a[1]).slice(0, 20);
  console.table(palette.map(([color, uses]) => ({ color, uses })));
  return palette.map(([c]) => c).join('\n');
})()

It reads the computed text, background, border and SVG fill color of every visible element and prints a table of up to 20 colors, ordered by how many times each is used. The return value is the hex list, one per line, ready to copy. Results from our runs:

PageTop colors
example.com#000000 #eeeeee #0000ee (3 in total, matching its CSS: background #eee and default link blue)
Wikipedia article#000000 #202122 #3366cc #404244 #fdfdfd (18 in total)

Limits: colors inside images, gradients and shadows are not counted, and only what is on the page right now is counted, not hover states or other pages. Colors the browser reports in newer formats (such as oklch()) are skipped by the hex conversion. Visit two or three typical pages of a site to get its full palette.

2. The site's color variables (design tokens)

Many sites define their palette as CSS custom properties such as --color-base. This snippet lists every variable that holds a color, with its current value:

(() => {
  const names = new Set();
  const walk = rules => { for (const r of rules) {
    if (r.style) for (const p of r.style) if (p.startsWith('--')) names.add(p);
    if (r.cssRules) walk(r.cssRules); // @media, @layer, @supports, nested rules
  } };
  for (const sheet of document.styleSheets) {
    try { walk(sheet.cssRules); } catch { /* other-domain stylesheet: not readable */ }
  }
  const root = getComputedStyle(document.documentElement), out = {};
  for (const name of [...names].sort()) {
    const v = root.getPropertyValue(name).trim();
    if (/^(#[0-9a-f]{3,8}|rgba?\(|hsla?\(|oklch\(|oklab\()/i.test(v)) out[name] = v;
  }
  console.table(out);
  return Object.keys(out).length;
})()

It found 172 color variables on Wikipedia (for example --color-base: #202122, --color-progressive: #36c) and 1,365 on GitHub (--fgColor-default: #f0f6fc, --bgColor-default: #0d1117 in the dark theme our browser got). It reads rules nested in @media and @layer. A first version that read only plain :root rules found 0 on both sites. Stylesheets served from another domain can't be read by page scripts and are skipped, and example.com and Stripe returned none.

Frequently asked questions

How do I find the exact color of one element?

Right-click it → Inspect, and look at color or background-color in the Styles or Computed tab. Click the color swatch to see it in other formats. An extension like ours does the same in one click.

Why does the snippet show colors I can't see?

It counts every visible element, including thin borders and default link colors (#0000ee) on links you may not notice. Treat colors with only a few uses as minor.

Is it OK to use another site's colors?

Colors themselves are not protected, but copying a whole brand identity can confuse customers. Use palettes as inspiration, and never imitate a company's branding.

Does this work in Firefox and Safari?

The snippets only use standard browser APIs. We ran them in Chromium only.
