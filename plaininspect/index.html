PlainInspect

Hover any text to see its font, size, weight and colors. See every font and color a page uses. No tracking.

What it does

  • Inspect mode: hover any element to see font family, size / line-height, weight, letter-spacing, text color and the background it sits on, plus the full font stack
  • WCAG contrast ratio with AA / AAA pass-fail (large-text aware) for every element you hover; click to pin, Esc to exit
  • Page summary: every font style the page uses (with counts) and its text and background color palettes
  • Click any color to copy its hex code
  • Export the whole palette + fonts as CSS variables, SCSS, Tailwind (v4 @theme or v3 config) or JSON

Frequently asked questions

Is PlainInspect a WhatFont alternative?

Yes. Like WhatFont it shows the font of any text you hover. It also shows colors, the WCAG contrast ratio and a page-wide summary of fonts and colors. (WhatFont had not been updated since March 2024 at the time of our research.)

Can it replace a color picker like ColorZilla for page colors?

For colors used in a page's CSS, yes: the page summary lists text and background colors and you can click any swatch to copy its hex. It does not pick colors from inside images.

Can I export a site's colors to Tailwind?

Yes. Export the palette and fonts as a Tailwind v4 @theme block or a v3 config, or as CSS variables, SCSS or JSON.

Does it check contrast?

Yes. Each hovered element shows its contrast ratio against its effective background with AA / AAA pass-fail.

Is there a web version?

The free color palette to CSS variables / Tailwind converter on this site turns a list of hex colors into the same export formats, and the free color contrast checker computes the same WCAG ratio for any two colors you enter.
