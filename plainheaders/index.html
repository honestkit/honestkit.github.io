PlainHeaders

Add, change or remove HTTP request & response headers. Open source, no tracking, access only to sites you choose.

Add PlainHeaders to Chrome — free

What it does

  • Set, append or remove request and response headers (Authorization, CORS, CSP, User-Agent, X-Forwarded-For…)
  • One-click presets: CORS allow-all, remove CSP / X-Frame-Options, disable caching, mobile user agent
  • “This tab only”: lock a profile to the current tab so other tabs stay untouched
  • Profiles you can switch in one click; pause everything instantly; the badge shows the active header count
  • Import your ModHeader export (JSON) or PlainHeaders backups; export any time
  • Host access is requested per site when you click “Enable on this site” — never all sites at install

Price

Free, with no header limit and no nagging. A planned optional Pro upgrade ($7 one-time) will add several profiles at once, URL filters per profile and URL redirects.

Privacy

No analytics, no ads, no remote code. Headers are applied with Chrome's declarativeNetRequest, so the extension never sees request contents. Site privacy policy.

Frequently asked questions

Is PlainHeaders a ModHeader alternative?

Yes. ModHeader was removed from the Chrome Web Store in July 2026. PlainHeaders covers the core job — setting, appending and removing request and response headers with switchable profiles — and can import a ModHeader JSON export, so you can bring your existing profiles over.

Can I import my ModHeader profiles?

Yes. Export your profiles from ModHeader as JSON, then use Import in PlainHeaders. PlainHeaders backups use the same import button.

Why does it ask for access per site?

Chrome only applies header changes on sites an extension can access. Instead of asking for every site at install time, PlainHeaders requests access only for the sites you enable.

Is there a limit on the number of headers?

No. The free version has no header limit.

Does it collect any data?

No. There are no analytics and no remote code. The only planned network call is the license check for the optional Pro upgrade (via ExtensionPay).
