HTML to Markdown converter

Paste HTML and get Markdown back. Supports headings, paragraphs, links and images (optionally made absolute with a base URL), nested lists, blockquotes, inline code and fenced code blocks with language hints, bold / italic and GitHub-flavoured tables. Scripts and styles are dropped.

Want this on any live page in one click? MDGrab — Turn any article or selection into clean Markdown for Obsidian, notes or LLM prompts. No signup, no limits, no tracking.
Need clean Markdown from hundreds of URLs? Article Scraper & Text Extractor – Clean Markdown for LLM/RAG (hosted, pay per result)

Frequently asked questions

Which Markdown flavour is produced?

CommonMark with GitHub-flavoured tables and fenced code blocks.

Can it convert a whole web page?

It converts whatever HTML you paste, including navigation and footers. To get just the article from a live page, MDGrab uses Mozilla Readability to strip the clutter first.

Are relative links fixed?

Yes, if you enter a base URL — relative links and image sources are resolved against it.

Is my HTML uploaded?

No. The conversion runs entirely in this page.
