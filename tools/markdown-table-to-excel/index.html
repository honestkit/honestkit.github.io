Markdown table to Excel / CSV

Paste a Markdown table, or a whole Markdown file: every table is found (code blocks are skipped). Pick a table and a format, then copy or download. Cells become plain text: **bold**, `code` and [link](url) markers are removed, \| becomes | and <br> becomes a line break inside the cell (CSV and .xlsx; TSV uses a space so pasting keeps one row per line). Nothing is uploaded — the conversion runs in this page.

Frequently asked questions

How do I paste a Markdown table into Excel or Google Sheets?

Choose TSV, click Copy, then click a cell in the spreadsheet and paste: rows and columns land in separate cells. Or download the .xlsx or CSV file.

What happens to rows with missing or extra cells?

Short rows are padded with empty cells. Rows with more cells than the header keep them as extra columns (GitHub would silently drop them), so no data is lost.

Can I keep the Markdown formatting in the cells?

Yes. Set Cells to 'keep Markdown' and the cell text is copied as written, with only \| turned back into |.

Why do some CSV cells start with an apostrophe?

Cells that begin with =, +, - or @ are prefixed so spreadsheets don't run them as formulas (CSV formula-injection guard). The TSV and .xlsx outputs keep the text as is.

Is my data sent to a server?

No. The page has no analytics and makes no network requests with your input.
