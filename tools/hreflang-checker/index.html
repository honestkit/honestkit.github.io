hreflang checker

Paste the page source (View source, Ctrl+A, Ctrl+C), just the <link rel="alternate" hreflang=…> tags, or the <xhtml:link> entries from a sitemap. Add the page's own URL to check that it lists itself. Codes are checked against ISO 639-1 languages, ISO 15924 scripts and ISO 3166-1 countries, as Google requires. Nothing is uploaded.

    Frequently asked questions

    Is it en-UK or en-GB?

    en-GB. hreflang regions are ISO 3166-1 country codes, and the United Kingdom's code is GB. 'uk' is the language code for Ukrainian, so hreflang="uk" means Ukrainian.

    Do I need x-default?

    It is recommended, not required: x-default names the page for visitors whose language or region matches none of your codes, often a language picker or the international homepage.

    Why must each page list itself?

    Google requires every version to list all versions including itself, and the other pages must link back. A page missing from its own list, or a link that is not returned, can make Google ignore the annotation.

    Can I use es-419 for Latin America?

    Google supports only ISO 3166-1 country codes as regions, not UN M.49 areas such as 419. Use plain 'es', or one code per country.

    Does it check the other pages link back?

    No, that needs fetching every listed URL, which a browser page cannot do across sites. Check each version's source here, or crawl the site with the SEO audit below.
