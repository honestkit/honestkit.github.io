curl to fetch / Python / axios

Paste a curl command — DevTools → Network → right-click a request → Copy → Copy as cURL (bash) works well. Method, URL, -H headers, -d/--data-raw/--json/--data-urlencode bodies, -G query data, -F multipart forms and file uploads, -u basic auth, -b cookies and -A user agent are converted. Nothing is uploaded — parsing runs in this page.

Need to change headers on real browser requests? PlainHeaders — Add, change or remove HTTP request & response headers. Open source, no tracking, access only to sites you choose.

Frequently asked questions

Does it send my request or token anywhere?

No. The command is parsed in your browser; the page makes no network requests with your input. Still, remove real tokens before sharing the generated code.

Is JSON body detected?

Yes. If Content-Type is JSON and the body parses, fetch gets JSON.stringify(...), Python gets json=payload and axios gets an object.

Which curl options are supported?

-X, -H, -d / --data / --data-raw / --data-binary / --data-urlencode, --json, -G, -F / --form, -I, -u, -b, -A, -e and --url, plus bash $'...' quoting from Chrome's Copy as cURL. Like curl, -d without a Content-Type is sent as a form (application/x-www-form-urlencoded). Output and connection flags such as -o, -s, -L, --max-time or -x are ignored.

Is the generated code tested?

Yes. We send each sample command with real curl and with the generated Python and fetch code to the same echo server and compare method, URL, content type, cookies, auth and body. That check found and fixed -G, --data-urlencode, -F and $'...' handling.

What about Windows cmd “Copy as cURL”?

Use the bash variant; cmd escaping with ^ is only partly supported.

Can I set headers on real browser requests instead?

PlainHeaders adds or changes request and response headers for the sites you choose, with switchable profiles.
