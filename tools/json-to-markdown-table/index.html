JSON to Markdown table

Paste a JSON array of objects — or a whole API response: the first array of objects inside it is used. Each object becomes a row; nested objects become columns like address.city. Nothing is uploaded — the conversion runs in this page.

Need a web page as Markdown? MDGrab — Turn any article or selection into clean Markdown for Obsidian, notes or LLM prompts. No signup, no limits, no tracking.

Frequently asked questions

Where can I use the Markdown table?

READMEs, GitHub/GitLab issues and PRs, Obsidian, docs sites and LLM prompts all accept GitHub-flavored Markdown tables.

How are nested objects and arrays handled?

Nested objects flatten to dot-notation columns; arrays of plain values are joined with “; ”; arrays of objects stay as JSON text in one cell.

Can I get CSV or Excel instead?

Yes — switch the format to CSV or TSV, or download .xlsx.

Is my data sent to a server?

No. The page has no analytics and makes no network requests with your input.
