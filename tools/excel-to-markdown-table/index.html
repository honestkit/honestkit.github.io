Excel / Google Sheets to Markdown table

Select cells in Excel, Google Sheets, LibreOffice or Numbers, copy (Ctrl/Cmd+C) and paste below. Copied cells arrive as tab-separated text, which is detected automatically; the first row becomes the header. Nothing is uploaded — the conversion runs in this page.

Frequently asked questions

Does it keep formatting like bold or colors?

No — Markdown tables hold plain text. Cell values are copied as displayed; pipes are escaped and line breaks become <br>.

Can I use it for Reddit, GitHub or Obsidian?

Yes. The output is GitHub-flavored Markdown table syntax, which GitHub, GitLab, Reddit (Markdown mode), Obsidian and most docs tools render.

What if my first row isn't a header?

Markdown tables require a header row. Add a header row in your sheet before copying, or edit the first line of the result.

Can I convert a CSV file instead?

Yes — open it in a text editor and paste the contents; commas, semicolons and pipes are auto-detected too.

Is my data sent to a server?

No. The page has no analytics and makes no network requests with your input.
