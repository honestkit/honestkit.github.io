Compare two lists

Paste one item per line in each box, for example two columns copied from Excel. The result lists the items only in List A, only in List B, and in both, each without duplicates and in the original order. Nothing is uploaded.

Frequently asked questions

How do I compare two columns in Excel?

Copy each column and paste it here. Inside Excel, =COUNTIF(B:B, A2)=0 next to column A marks the items of A that are missing from B; fill it down and filter on TRUE.

Does it ignore uppercase and spaces?

By default 'Apple', 'apple' and ' apple ' count as the same item, and the first spelling is shown. Untick the options to compare exactly.

Are duplicates counted?

No. Each list is de-duplicated first, so the result shows each distinct item once. The status line shows how many distinct items each list has.

Is my data sent to a server?

No. The page has no analytics and makes no network requests with your input.
