HTML table to CSV / TSV / Markdown

Paste HTML that contains one or more <table> elements. Pick a table and a format, then copy or download the result. Merged cells (colspan / rowspan) are expanded into a rectangular grid. Nothing is uploaded — the conversion runs in this page.

Frequently asked questions

How do I get the HTML of a table?

In Chrome, right-click the table → Inspect, right-click the <table> element → Copy → Copy outerHTML, then paste it here. Or install PlainTables and skip this step.

Which format should I use for Excel or Google Sheets?

TSV (tab-separated) pastes straight into cells. Use CSV or XLSX if you want a file.

Why do some CSV cells start with an apostrophe?

Cells that begin with =, +, - or @ are prefixed so spreadsheets don't run them as formulas (CSV formula-injection guard).

Is my data sent to a server?

No. The page has no analytics and makes no network requests with your input.
