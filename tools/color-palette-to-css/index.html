Color palette to CSS variables / Tailwind

Paste colors one per line or separated by commas or spaces. You can name them (brand: #0e7c66 or --brand: #0e7c66); unnamed colors are numbered. Accepts #rgb, #rrggbb, #rrggbbaa and rgb()/rgba(). Duplicates are removed.

Want this on any live page in one click? PlainInspect — Hover any text to see its font, size, weight and colors. See every font and color a page uses. No tracking.

Frequently asked questions

Does it support Tailwind v4?

Yes: the v4 output is an @theme block with --color-* variables, which Tailwind v4 turns into utilities like bg-brand.

How are names generated?

Names you provide are turned into lowercase-dash slugs; unnamed colors get the prefix you choose plus a number.

Can I grab a live site's palette?

PlainInspect lists every text and background color a page uses and exports them in these same formats.

Is anything uploaded?

No. Everything runs in this page.
