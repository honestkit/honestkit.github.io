Extract links from HTML

Paste HTML (for example a page's source) to list every <a href>. Add the page's URL as base to resolve relative links and mark internal vs external links. Duplicates are removed (optionally ignoring #anchors); javascript: links are skipped.

Frequently asked questions

How do I get a page's HTML?

Press Ctrl+U (Cmd+Option+U on Mac) to view source, select all and copy. PlainLinks does this in one click on the live page, including links added by JavaScript.

Can I filter by regular expression?

Yes. Type /pattern/ in the filter box, e.g. /\.pdf$/ for PDF links.

What does the CSV contain?

URL, anchor text, rel, whether it opens in a new tab, and whether it is internal (same host as the base URL).

Is anything uploaded?

No. Everything runs in this page.
