XML to CSV / Excel converter

Paste XML. The tool finds the element that repeats (an RSS <item>, a sitemap <url>, a <record>…) and makes one row per element; pick another in Row element if needed. Attributes become element@name columns, nested elements parent/child, repeated children name, name_2. Tested on 2026-10-01 against Python's ElementTree on the BBC News RSS feed (38 items) and the sitemaps.org sitemap (84 URLs): identical values. Nothing is uploaded.

Frequently asked questions

How do I open XML in Excel as a table?

Convert it here and click Download .xlsx, or choose TSV, copy and paste into a cell. Excel's own XML import needs the Developer tab and an XML map.

What happens to namespaces like media:thumbnail or image:loc?

The prefix is kept in the column name (media:thumbnail@url), so columns from different namespaces do not collide.

Why is a value split into name and name_2?

The element appears more than once in that record (two authors, say). Each occurrence gets its own column so nothing is lost.

Is my data sent to a server?

No. The XML is parsed by your browser's own parser; the page has no analytics and makes no network requests with your input.
