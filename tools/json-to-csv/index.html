JSON to CSV / Excel

Paste a JSON array of objects — or a whole API response: the first array of objects inside it is used. Nested objects become columns like address.city; lists of plain values are joined with “; ”. Nothing is uploaded — the conversion runs in this page.

Data in a web page table instead? PlainTables — Copy any web table to Excel, Google Sheets, CSV or Markdown in one click. No row limits, no account, no tracking.

Frequently asked questions

What JSON shapes are supported?

An array of objects, a single object, or an object wrapping an array (e.g. {"results": [...]}) — the first array of objects is converted.

How are nested objects handled?

They are flattened into dot-notation columns (address.city). Arrays of plain values are joined with “; ”; arrays of objects are kept as JSON text in one cell.

What if objects have different keys?

Columns are the union of all keys in first-seen order; missing values are left empty.

Will Excel run formulas from my data?

No. CSV cells starting with =, +, - or @ are prefixed with an apostrophe (formula-injection guard).

Is my data sent to a server?

No. The page has no analytics and makes no network requests with your input.
