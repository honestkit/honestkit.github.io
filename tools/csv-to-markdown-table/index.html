CSV to Markdown table

Paste CSV (or copy cells from Excel / Google Sheets, which gives tab-separated text). The first row becomes the header. Pipes inside cells are escaped so the Markdown table doesn't break. Nothing is uploaded — the conversion runs in this page.

Need a Markdown table from a web page? PlainTables — Copy any web table to Excel, Google Sheets, CSV or Markdown in one click. No row limits, no account, no tracking.

Frequently asked questions

Can I paste straight from Excel or Google Sheets?

Yes. Copied cells are tab-separated; the delimiter is detected automatically (comma, tab, semicolon or pipe), or you can pick it.

What happens to line breaks inside a quoted cell?

Quoted cells may contain commas, quotes and line breaks. In the Markdown output line breaks become <br> because a Markdown table row must be a single line.

Where does the Markdown table work?

GitHub, GitLab, Obsidian, Notion import, most static-site generators and README files use this GitHub-flavored table syntax.

Can I get a table from a web page instead?

Use the HTML table converter on this site, or PlainTables to copy any table on a live page as Markdown in one click.

Is my data sent to a server?

No. The page has no analytics and makes no network requests with your input.
