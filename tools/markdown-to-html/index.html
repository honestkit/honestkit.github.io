Frequently asked questions

Is raw HTML in my Markdown kept?

Not by default: tags like <script> or <img onerror> are escaped and shown as text, so pasted Markdown can't inject code. Tick “Allow raw HTML” only for Markdown you wrote or trust; the preview stays sandboxed with scripts disabled either way.

Are javascript: links blocked?

Yes. Link and image targets starting with javascript:, vbscript:, file: or data: (other than data: images) are replaced with #, even when raw HTML is allowed.

Which Markdown flavour is supported?

CommonMark-style blocks and inline syntax plus GitHub-flavored tables and strikethrough. Footnotes, task-list checkboxes and heading IDs are not generated.

Can I get a complete HTML file?

Yes — tick “Full HTML document” to wrap the output in <!doctype html>, <head> and <body> (the first heading becomes the <title>), then download it as .html.

Why don't remote images show in the preview?

The preview blocks network requests so that nothing leaves this page. The HTML output keeps your image URLs unchanged.

Is my text sent to a server?

No. The page has no analytics and makes no network requests with your input.
