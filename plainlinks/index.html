What it does

Frequently asked questions

Is PlainLinks a Link Klipper alternative?

Yes. Link Klipper is no longer available because it was not updated for Manifest V3. PlainLinks extracts the links on a page or selection and exports them to CSV or Excel, which covers the same use.

Can I extract only PDF links?

Yes. Use the documents filter (PDF, Word, Excel and more) or type a regular expression such as /\.pdf$/.

Does it remove duplicate links?

Yes. Duplicates are removed automatically; links that differ only by #anchor count as the same link.

Is it useful for SEO audits?

Yes. Exports include the rel attribute (nofollow is tagged) and whether each link is internal or external.

Can I try it without installing?

Yes — paste HTML into the free link extractor on this site.
